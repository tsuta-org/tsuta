# Tsuta

Tsuta（蔦） - A lightweight federated social network built for the free tier.

## Features
- ActivityPub support (required)
- Mastodon API compatible
- Cloudflare Workers + Docker dual support
- Plugin system with permission management
- TUI client (Go + Bubble Tea)

## Tech Stack
- Core: TypeScript + Hono
- ORM: Drizzle ORM
- Database: D1 / SQLite / PostgreSQL
- Storage: R2 / S3 compatible
- Queue: Cloudflare Queues / custom
- TUI: Go + Bubble Tea
